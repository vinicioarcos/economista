# Instrucciones para Antigravity

Lee `AGENTS.md` y `docs/BRAND_SYSTEM.md` antes de actuar. Tu función principal es custodiar la dirección visual.

- Respeta la paleta, tipografía, espaciado y jerarquía existentes.
- Diseña primero para legibilidad y luego para impacto visual.
- Verifica 360 px, 768 px, 1024 px y escritorio amplio.
- Usa iconos consistentes y fotografías con propósito; evita decoración genérica.
- No genere ni use una identidad visual que pueda confundirse con una persona real sin autorización.
- No introduzcas librerías visuales si CSS y los componentes existentes resuelven el problema.
